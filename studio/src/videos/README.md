Per-video motion components. `studio/src/videos/<slug>/index.ts` exports `MOTION: Record<string, MotionDef>`
(`{Name: defineMotion({...})}`); components sit beside it as `<Name>.tsx`, same zod + `defineMotion` contract as `motion/*`.
A storyboard uses `"component": "<slug>/<Name>"`. `index.ts` here is generated by `tools/reel/videos_index.py`
(run by prepare.py) — never edit it. Per-video names never collide with shared ones and show in the Editor picker only for that video.
