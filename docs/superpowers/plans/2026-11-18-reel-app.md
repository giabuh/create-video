# Reel Studio App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local web app (`app/`) over the create-video engine files: browse projects, live-preview and edit storyboards, generate voices, render/compare/approve versions, upload and describe media, audition voices, edit brands and settings.

**Architecture:** One npm workspace (`studio` + `app`) so React/Remotion exist once. `app/server` is a Hono API server run directly by Node 24 (TypeScript type-stripping, no build) on `127.0.0.1:5316`; the UI is always served by Vite on `127.0.0.1:5317` (proxying `/api` and media roots to 5316), so edits Claude makes in `studio/src` hot-reload into the preview with no rebuild. The API server serves the media roots, a JSON API, SSE events, a job queue, a long-lived Python TTS worker and in-process Remotion renders. `app/src` is a React SPA (Vite) with a custom UI kit (Radix primitives + our tokens), TanStack Query for data/loading states, and `@remotion/player` rendering the studio's `Reel` composition for instant preview.

**Tech Stack:** Node 24, TypeScript 5.9.3, Hono 4 + @hono/node-server 2, Vite 8 + @vitejs/plugin-react 6, React 19.3.1, Remotion 4.0.544 (`remotion`, `@remotion/player`, `@remotion/bundler`, `@remotion/renderer`, `@remotion/media`, `@remotion/google-fonts`), radix-ui 1.8, @dnd-kit/core + @dnd-kit/sortable, @tanstack/react-query 5, react-router 8, lucide-react 1, vitest 5, @playwright/test; Python 3 (system) for `prepare.py --preview`/`ingest.py`; `VieNeu-TTS/.venv/bin/python` for `tools/worker.py`.

Spec: `docs/superpowers/specs/2026-11-18-reel-app-design.md`. Engine spec (file contract): `docs/superpowers/specs/2026-11-18-reel-pipeline-design.md`. Visual reference: `docs/superpowers/mockups/reel-app/*.dc.html` (read the markup; they do not render standalone — match layout, hierarchy, copy and colors, not their CSS mechanics).

## Global Constraints

- Never edit `VieNeu-TTS/`. Never read, print or serve `~/.config/rclone/*`. Never commit secrets.
- Exact pins: `remotion`, `@remotion/*` = `4.0.544`; `react`, `react-dom` = `19.3.1`; `typescript` = `5.9.3`. All other new deps: exact versions (no `^`) as listed in Task 1 Step 3 (resolved together on 2026-11-18).
- All new deps are added in Task 1 only. Later tasks must not change `package.json` files; if a task truly needs a new dep, report NEEDS_CONTEXT.
- Server code runs with plain `node` (Node 24 type stripping): erasable TypeScript only (no `enum`, no `namespace`, no parameter properties), `import type` for types, relative imports with the `.ts` extension, no `@studio` alias in `app/server` or `app/shared` (Node does not read tsconfig paths).
- Server binds `127.0.0.1` only. API port `5316`; UI (Vite, also in normal use) port `5317`, proxying `/api` and media roots to 5316 without `changeOrigin`. There is no production build/dist serving.
- UI copy is Vietnamese (as in the mockups). Code, comments, commit messages in English.
- Commit messages: a single line, no body, no Co-Authored-By trailer. Stage only your own files by explicit path (other workers share the tree) and commit with a pathspec so a sibling's staged files are never included: `git add -- <paths> && git commit -m "<msg>" -- <paths>`; retry once on an `index.lock` error.
- Parallel workers edit the same tree: type errors or test failures in files outside your task are not yours — report them, do not fix them.
- Throwaway scripts (Playwright checks, smoke runs) and their screenshots go in `app/.scratch/` (git-ignored, created in Task 1), run with `cd app && node .scratch/<x>.mjs`, and are deleted before you commit. Never put them outside the repo: Node cannot resolve `@playwright/test` from there.
- React components: write `React.JSX.Element` or omit the return type (`@types/react` 19 has no global `JSX`).
- Testing cadence: run only the tests for the files you touched (`cd app && npx vitest run <file>`, `uv run --with pytest python -m pytest tools/tests/<file> -q`, `cd app && npx tsc --noEmit`). The full suite runs only at final review.
- Never overwrite a render: versions are `projects/<slug>/reel-vN.mp4`, N = max existing + 1.
- Never invent ad facts (prices, phones, dates, addresses) in fixtures or UI defaults; use `[GIÁ]`-style placeholders.
- UI: base font 16px (`1rem`), labels/meta ≥ 14px, nothing below 13px; all sizes in `rem`; every interactive element keyboard-operable with a visible focus ring, ≥ 44px hit target for primary controls, `aria-label` on icon-only buttons; respect `prefers-reduced-motion`.
- Loading/feedback rules from the spec section "Loading & feedback states" apply to every screen task (skeletons after 150 ms, button loading state, determinate progress, empty/error states with retry).

```ts
export type TryVariant = {file: string; ref: string; tts: Json; seconds: number};
export type Tries = {voice: string; text: string; variants: Record<string, TryVariant>};

export type BrandFile = {name: string; logo: string | null; colors: {primary: string; accent: string; text: string; background: string}; cta?: {phone?: string; fanpage?: string; address?: string}; captions?: Json};
export type BrandSummary = {id: string; brand: BrandFile; isDefault: boolean; mtime: number}; // mtime of brands/<id>/brand.json, used as baseMtime
export type Config = Json & {
  defaults: {voice: string; template: string; brand: string};
  tts: Json & {speed: number; pauseAfter: number}; voices: Record<string, Json & {ref: string}>;

export type JobState = 'queued' | 'running' | 'done' | 'failed' | 'cancelled';
```

```python
"""Engine steps shared by the CLIs (prepare.py, voice_try.py) and the app's TTS worker (worker.py)."""
import json
import os
from pathlib import Path

from .cache import cache_key
from .config import ROOT, load_json, resolve_names, resolve_scene_voice, resolve_video
from .mix import mix
from .props import build_render_props
from .tts import probe_duration, synth_to_file
from .validate import validate

# shortcut: rough Vietnamese speaking rate for scenes not synthesized yet (preview only); real audio replaces it.
CHARS_PER_SECOND = 14


def write_json(path: Path, data) -> None:
    tmp = path.with_name(f"{path.name}.{os.getpid()}.tmp")  # pid: the app may run preview and worker prepare concurrently
    tmp.write_text(json.dumps(data, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
    tmp.replace(path)


def prepare(proj: Path, get_model=None, synth: bool = True, on_progress=None) -> dict:
    """Validate, (optionally) synthesize, write render-props.json (+ timings.json when synth). Never raises on bad input."""
    proj = Path(proj)
    slug = proj.name
    sb = load_json(proj / "storyboard.json")
    cfg = load_json(ROOT / "config.json")
    target = cfg.get("mix")
    errs = validate(sb, cfg, ROOT)
    if errs:
        return {"ok": False, "stage": "validate", "errors": errs, "stale": [], "totalSeconds": None, "mix": None,
                "target": target, "targetSeconds": sb.get("targetSeconds")}
    _, brand_id = resolve_names(cfg, sb)
    brand = load_json(ROOT / "brands" / brand_id / "brand.json")
    settings = resolve_video(cfg, brand, sb)
    old = load_json(proj / "timings.json").get("scenes", {}) if (proj / "timings.json").exists() else {}

    spoken = [sc["id"] for sc in sb["scenes"] if sc.get("say") is not None]
    model, audio, timings, failed, stale, scenes = None, {}, {}, [], [], []
    for sc in sb["scenes"]:
        if sc.get("say") is None:
            timings[sc["id"]] = {"duration": float(sc["duration"])}
            scenes.append(sc)
            continue
        v = resolve_scene_voice(cfg, sb, sc)
        ref = ROOT / v["ref"]
        key = cache_key(ref.read_bytes(), sc["say"], v["tts"])
        out = proj / "audio" / f"{sc['id']}-{key}.wav"
        if not synth and not out.exists():
            est = old.get(sc["id"], {}).get("duration") or len(sc["say"]) / CHARS_PER_SECOND
            stale.append(sc["id"])
            scenes.append({**sc, "duration": round(est + v["pauseAfter"], 3)})
            continue
        done = spoken.index(sc["id"])
        if on_progress:
            on_progress(done, len(spoken), sc["id"])
        try:
            if out.exists():
                dur = probe_duration(out)
            else:
                if model is None:
                    model = get_model()
                dur = synth_to_file(model, sc["say"], ref, v["tts"], out)
        except Exception as e:  # report per scene; cached scenes stay valid
            failed.append(f"{sc['id']}: {e}")
            continue
        if on_progress:
            on_progress(done + 1, len(spoken), sc["id"])
        audio[sc["id"]] = {"src": f"projects/{slug}/audio/{out.name}", "duration": dur, "pauseAfter": v["pauseAfter"]}
        timings[sc["id"]] = {"duration": dur, "pauseAfter": v["pauseAfter"], "voice": v["voice"],
                             "ref": v["ref"], "tts": v["tts"], "cacheKey": key}
        scenes.append(sc)
    if failed:
        return {"ok": False, "stage": "tts", "errors": failed, "stale": stale, "totalSeconds": None, "mix": None,
                "target": target, "targetSeconds": sb.get("targetSeconds")}

    props = build_render_props({**sb, "scenes": scenes}, settings, brand, audio)
    cta_s = props["cta"]["duration"] if props["cta"] else 0
    actual = mix([{"duration": s["duration"], "hasMedia": bool(s["media"])} for s in props["scenes"]], cta_s)
    write_json(proj / "render-props.json", props)
    if synth:
        write_json(proj / "timings.json", {"scenes": timings, "totalSeconds": props["totalSeconds"], "mix": actual})
    return {"ok": True, "stage": None, "errors": [], "stale": stale, "totalSeconds": props["totalSeconds"],
            "mix": actual, "target": target, "targetSeconds": sb.get("targetSeconds")}


def try_variants(model, voice: str, text: str, variants: list[dict], on_progress=None) -> dict:
    """Synthesize `text` once per variant into voices/tries/<voice>-<A..>.wav and write voices/tries/tries.json."""
    cfg = load_json(ROOT / "config.json")
    if voice not in cfg["voices"]:
        raise ValueError(f"Unknown voice '{voice}'. Known: {', '.join(cfg['voices'])}")
    out_dir = ROOT / "voices/tries"
    report = {}
    for i, over in enumerate(variants):
        over = dict(over)
        ref = over.pop("ref", None)
        v = resolve_scene_voice(cfg, {}, {"voice": voice, "tts": over})
        ref = ref or v["ref"]
        letter = chr(65 + i)
        if on_progress:
            on_progress(i, len(variants), letter)
        out = out_dir / f"{voice}-{letter}.wav"
        dur = synth_to_file(model, text, ROOT / ref, v["tts"], out)
        report[letter] = {"file": f"voices/tries/{out.name}", "ref": ref, "tts": v["tts"], "seconds": round(dur, 2)}
    out_dir.mkdir(parents=True, exist_ok=True)
    result = {"voice": voice, "text": text, "variants": report}
    write_json(out_dir / "tries.json", result)
    if on_progress:
        on_progress(len(variants), len(variants), None)
    return result
```

```ts
// store.ts (core of it)
import {mkdir, readFile, rename, stat, writeFile} from 'node:fs/promises';
import path from 'node:path';
import type {Versioned} from '../shared/types.ts';

export class Conflict extends Error {
  current: unknown; mtime: number;
  constructor(current: unknown, mtime: number) { super('conflict'); this.current = current; this.mtime = mtime; }
}
const locks = new Map<string, Promise<unknown>>();
function withLock<T>(file: string, fn: () => Promise<T>): Promise<T> {
  const prev = locks.get(file) ?? Promise.resolve();
  const next = prev.catch(() => {}).then(fn);
  locks.set(file, next);
  next.finally(() => { if (locks.get(file) === next) locks.delete(file); }).catch(() => {});
  return next;
}
export const mtimeOf = async (file: string) => Math.floor((await stat(file)).mtimeMs);
export async function readJson<T>(file: string): Promise<Versioned<T>> {
  const [text, mtime] = await Promise.all([readFile(file, 'utf8'), mtimeOf(file)]);
  return {data: JSON.parse(text) as T, mtime};
}
export async function readJsonOr<T>(file: string, fallback: T): Promise<Versioned<T>> {
  try { return await readJson<T>(file); } catch (e) { if ((e as NodeJS.ErrnoException).code === 'ENOENT') return {data: fallback, mtime: 0}; throw e; }
}
export function writeJsonAtomic(file: string, data: unknown, baseMtime?: number | null): Promise<number> {
  return withLock(file, async () => {
    if (baseMtime != null) {
      let cur: Versioned<unknown> | null = null;
      try { cur = await readJson(file); } catch (e) { if ((e as NodeJS.ErrnoException).code !== 'ENOENT') throw e; }
      if (cur && cur.mtime !== baseMtime) throw new Conflict(cur.data, cur.mtime);
    }
    await mkdir(path.dirname(file), {recursive: true});
    const tmp = `${file}.${process.pid}.${Date.now()}.tmp`;
    await writeFile(tmp, JSON.stringify(data, null, 2) + '\n', 'utf8');
    await rename(tmp, file);
    return mtimeOf(file);
  });
}
```

```python
#!/usr/bin/env python3
"""Long-lived TTS worker for the app: JSON lines on stdin -> JSON lines on stdout. Logs go to stderr.

Run with: VieNeu-TTS/.venv/bin/python tools/worker.py
"""
import json
import os
import re
import sys
import traceback
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from reel import pipeline  # noqa: E402

SLUG = re.compile(r"^[a-z0-9_][a-z0-9_-]{0,63}$")


def load_model():
    from reel.tts import load_model as real
    return real()


def detect_device():
    try:
        import torch
        return "cuda" if torch.cuda.is_available() else "cpu"
    except Exception:
        return "cpu"


class Worker:
    def __init__(self, loader=load_model, out=sys.stdout):
        self.loader, self.out, self.model, self.device = loader, out, None, None

    def send(self, obj) -> None:
        self.out.write(json.dumps(obj, ensure_ascii=False) + "\n")
        self.out.flush()

    def get_model(self):
        if self.model is None:
            self.send({"event": "model", "state": "loading"})
            try:
                self.model = self.loader()
            except Exception as e:
                self.send({"event": "model", "state": "error", "error": str(e)})
                raise
            self.device = detect_device()
            self.send({"event": "model", "state": "ready", "device": self.device})
        return self.model

    def handle(self, req: dict) -> dict:
        rid, cmd = req.get("id"), req.get("cmd")
        progress = lambda done, total, label: self.send({"id": rid, "event": "progress", "done": done, "total": total, "label": label})  # noqa: E731
        if cmd == "ping":
            return {"id": rid, "ok": True, "modelLoaded": self.model is not None, "device": self.device}
        if cmd == "prepare":
            slug = str(req.get("project", ""))
            if not SLUG.match(slug):
                return {"id": rid, "ok": False, "errors": [f"bad project: {slug}"]}
            res = pipeline.prepare(pipeline.ROOT / "projects" / slug, self.get_model, synth=True, on_progress=progress)
            return {"id": rid, **res}
        if cmd == "try":
            tries = pipeline.try_variants(self.get_model(), req["voice"], req["text"], req.get("variants") or [{}], on_progress=progress)
            return {"id": rid, "ok": True, "tries": tries}
        return {"id": rid, "ok": False, "errors": [f"unknown cmd: {cmd}"]}

    def feed(self, line: str) -> None:
        line = line.strip()
        if not line:
            return
        try:
            req = json.loads(line)
        except json.JSONDecodeError as e:
            self.send({"id": None, "ok": False, "errors": [f"bad json: {e}"]})
            return
        try:
            self.send(self.handle(req))
        except Exception as e:  # keep serving after any failure
            traceback.print_exc(file=sys.stderr)
            self.send({"id": req.get("id"), "ok": False, "errors": [str(e)]})


def main() -> int:
    # VieNeu/torch may print to stdout; keep the protocol on a private dup of fd 1 and send fd 1 to stderr.
    proto = os.fdopen(os.dup(1), "w", encoding="utf-8")
    os.dup2(2, 1)
    sys.stdout = sys.stderr
    w = Worker(out=proto)
    w.send({"event": "ready"})
    for line in sys.stdin:
        w.feed(line)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## Spec deltas recorded by this plan

- `projects/<slug>/project.json` = `ProjectMeta` (`approved` + `renders` map of kind/time) — supersedes the spec's `{approved}`-only shape.
- Instant preview runs `python3 tools/prepare.py <proj> --preview --json` as a short-lived process (not the TTS worker) so previews never queue behind voice generation.
- npm workspace at the repo root; `setup.sh` runs `npm ci` at the root.
- The UI is always served by Vite (port 5317, also for `npm start`); the API runs on 5316. No dist build — edits to `studio/src` hot-reload into the preview.
- Render snapshots the storyboard bytes read at job start; preview and render-prepare are serialized per project.
- Voice refs are converted to 48 kHz mono (matches the existing refs; the spec's "24 kHz" is wrong).
- Library edits and deletes during ingest return 423 instead of waiting.
- Job progress carries a free-text `label` (step text) instead of a `scene` field.
- Adding a voice is one endpoint, `PUT /upload-voice/:name/:filename`, not `POST /voices` + upload.
- Retrying a failed job = pressing the same action again (no separate retry endpoint).
- Approving a version without a storyboard snapshot (rendered by the CLI) commits only `project.json`.
