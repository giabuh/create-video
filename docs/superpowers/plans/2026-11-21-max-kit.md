> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the pilot's "max" kit in the shared studio library on top of `ReelFrame`. This covers new transitions
with a `mix` rotation, light leaks, look knobs, 4 motion cards, pop captions, a 3D CTA and a `max` template. Then point
make-reel at it so reels stop looking templated.

**Architecture:**
- New storyboard fields flow through the existing pipeline: `validate.py` → `props.py` → `render-props.json` →
  `ReelFrame`.
- New transitions animate both scenes with `@remotion/transitions` presentation components inside `ReelFrame`. The old
  `cut`, `fade` and `slide` keep their path.
- The `max` template is a thin `ReelFrame` wrapper that picks pop captions, the 3D CTA and a look.

**Tech Stack:**
- Remotion 4.0.544 (React 19, zod 4).
- `@remotion/transitions`, `light-leaks`, `motion-blur`, `noise`, `shapes` and `three`.
- Python 3 tools with pytest.
